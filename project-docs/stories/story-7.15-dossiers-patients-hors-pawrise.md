# Story 7.15: Dossiers patients hors Pawrise

Status: drafted

> **Épic 7 — Vet Portal — consultation vétérinaire augmentée**
> Périmètre : Post-MVP
> Sources : brainstorm Vet Portal · MCD/MLD Vet Portal (`project-docs/data-model/`, vision post-MVP dans `data-model/post-mvp/`)

## Story

As a vétérinaire partenaire,
I want gérer dans le Portail les dossiers de tous mes patients, clients Pawrise ou non,
So that le Portail devienne mon outil de suivi au quotidien.

## Acceptance Criteria

**Given** un véto vérifié
**When** il crée le dossier d'un animal dont le propriétaire n'a pas l'app
**Then** il gère ce dossier comme les autres (notes, historique, rendez-vous)
**And** un client Pawrise a en plus les données du collier, avec son consentement.

## Précisions (à affiner avant d'entrer dans un sprint)

- Vision « SaaS 360 » du brainstorm : voir `data-model/post-mvp/`.
- Le client Pawrise ne quitte jamais l'app ; il n'est pas obligé d'avoir un espace sur le Portail.
- Le Portail n'utilise les données de l'app qu'avec l'accord explicite du propriétaire.
